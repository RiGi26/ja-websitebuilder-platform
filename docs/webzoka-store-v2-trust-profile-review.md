# Webzoka Store V2 — Trust Profile Review

## Purpose

Trust Profile is Template #3 for professional-services businesses that need to earn a consultation through clarity, process, and credible examples. The fictional brand is **Arta Studio**.

## Routes

- `/store`
- `/store/template/trust-profile`
- `/store/template/trust-profile/preview`

## Direction

- Typography-led editorial composition with warm paper, ink, and oxide accents.
- A single oversized decision-led hero and a printed practice-note art direction.
- Numbered services, selected-work studies, a four-step process, concise expertise, honest expectations, FAQ, and final consultation CTA.
- Selected work deliberately avoids invented metrics, logos, testimonials, or endorsements.

## Scope Boundaries

- The experience is static and intentionally has no CRM, client portal, account, payment, checkout, booking implementation, or Template #4 work.
- The consultation CTA opens an email client only. It does not submit data or create an account.
- Portal, CRM, booking, and internal-system capabilities are described only as possible future upgrades when a business needs them.

## Visual Distinction from Modern Catalog

Modern Catalog is product-first: cobalt, object study visuals, category filtering, variants, and a WhatsApp enquiry path. Trust Profile is credibility-first: editorial typography, numbered services, professional-process content, curated studies, and a consultation CTA.

## Review Checks

- Confirm all copy remains honest when replacing the fictional sample content.
- Confirm a real consultation destination before production activation.
- Preserve the 44px minimum target size and the 390px mobile layout when adapting this direction.
